# Agentic experiment demo — workshop template

This is the starting point for the live workshop progression. The scientist has supplied the protocol, data contract, audio assets, and project boundaries. The implementation is intentionally unfinished.

Start with `WORKSHOP_GUIDE.md`. The completed reference is in the sibling folder `agentic-experiment-demo-finished`.

## Environment

Use Python 3.10 or 3.11 and install `requirements.txt`. Tests of the scientific logic should not require PsychoPy.

Do not use this template to collect research data.
