# Experiment brief

Complete this document before asking an agent to implement the experiment. Unknown answers can remain marked `TBD`.

## Research objective

- What scientific question does the experiment address?
- What is the primary hypothesis?
- What is the primary outcome measure?

## Participants and sessions

- How many sessions does one participant complete?
- What participant identifier format is permitted?
- Does a later session depend on assignments or data from an earlier session?

## Trial

- What does the participant see, hear or feel during one trial?
- What marks trial onset and trial completion?
- Can stimuli overlap, or must each finish before the next trial?

## Responses and scoring

- Which responses are allowed?
- What determines a correct response?
- How are omissions, late responses and multiple responses handled?
- Can a participant pause or abort?

## Conditions

- Which experimental conditions exist?
- Which variables vary within participants and which vary between participants?
- What comparison does each condition support?

## Blocks

- Are trials grouped into blocks?
- How many blocks and trials are required?
- Does each block contain one condition or several conditions?
- How are block order, practice and breaks handled?

## Randomization and counterbalancing

- What must be randomized?
- What must remain balanced?
- Which sequences or repetitions are prohibited?
- How is counterbalancing assigned across participants?
- What information must be saved to reproduce the schedule?

- Stimulus duration:
- Response window:
- Inter-trial interval:
- Inter-block interval or break:
- Which timing claims require empirical measurement?

## Stimuli

- Which assets are required?
- How are assets categorized and validated?
- Are there licensing, privacy or redistribution restrictions?

## Triggers and external devices

- Which experimental events require codes?
- Which device or acquisition system receives them?
- What should simulation mode record?
- What must be verified on laboratory hardware?

## Data and exclusions

- What must be recorded for each session, block and trial?
- How are missing values represented?
- What makes a trial or session invalid?
- Should partial data be saved after an abort or error?

## Completion criteria

- What observable evidence will show that the implementation follows the protocol?
- Which checks can be automated?
- Which checks require scientist inspection or hardware measurement?
